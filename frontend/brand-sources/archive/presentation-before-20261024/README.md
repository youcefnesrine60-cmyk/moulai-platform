# Archived frontend presentation logos

These byte-identical PNGs were used before the user's explicit approval of the
new frontend display variants on 2026-10-24. Their original hashes and dimensions
remain in `logo-manifest.json`. They are retained as source history and are not
referenced by active UI components or copied into the public build.

The historical DAS reference remains unchanged at
`frontend/public/brand/moulai-logo.png`. Adopting the new web display variants
does not amend that reference or redefine the DAS geometry.
