# Third-party notices

MoulAI source licensing does not replace the licenses of its dependencies.
Exact versions and integrity records are in `package-lock.json`; original
package notices remain in each installed package.

The current self-hosted **Sora Variable** font is copyright The Sora Project
Authors. **Tajawal** is distributed with its original Google Inc. notice. Both
use SIL Open Font License 1.1. Their unmodified full notices are included in
`public/licenses/sora-OFL.txt` and `public/licenses/tajawal-OFL.txt`, which Vite
copies into the build. The previous Inter/Noto notices remain as historical
license records; those packages and font binaries are no longer bundled.
Font files are supplied by the pinned Fontsource packages. The CSS uses their
original subset definitions with local package URL resolution.

Lucide provides interface icons under its ISC license. They are generic UI
icons, not substitutes for the official MoulAI logo. Its original notice is
included in `public/licenses/lucide-ISC.txt`.

React, React Router, Radix, TanStack Query, React Hook Form, the resolvers,
i18next, react-i18next and Zod retain their respective original package licenses.
Build and test tools retain their own notices. No third-party service or CDN is
required to render the supplied local screens.
